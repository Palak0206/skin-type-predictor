# Skin Type Prediction and Product Recommendation

A machine learning project that aims to predict skin type using image and text inputs and recommend suitable skincare products.

## Planned Features
- Skin type prediction
- Image-based analysis using deep learning
- Text-based analysis using NLP
- Personalized skincare product recommendations

## Tech Stack
- Python
- PyTorch or TensorFlow
- NLP and CNN models
- Scikit-learn
- Flask (for the web application)

## Project Status
Currently in the initial setup phase.
